# 04 - World and assets

## Scene as data, minimal

One typed `SceneDef` (TypeScript, in app/ since only the client and bake tools read render fields; the sim gets a smaller `FieldDef` with bounds, gate, pen, spawn). Rules learned the hard way:

- The SceneDef contains only fields something actually reads, added in the same PR as the reader (sds accreted ~15 dead or promissory optional flags).
- Declaring a datum never implicitly switches on behavior. Behaviors are explicit config (sds: a non-null gate silently enabled worker gate-attraction hardcoded to x=0, so later features contorted their data to dodge it).
- Render-workaround flags never live in world data.
- One destination shape: the pen. Not three.
- The SceneDef is the sole authority for zones/radii; bake scripts read it, never carry their own copy (sds kept two diverged zone tables to satisfy old goldens).

## Field geometry

Start from Home Field's playtested numbers (spec/02). Terrain: gently rolling, baked at build time (seeded fBm to a small R32F grid + JSON manifest), read-only at runtime, sampled bilinearly. Port `sds/shared/terrain/Heightfield.js` for the sampler and the sample-vs-meshSampleY split. The relief is VISUAL ONLY: the sim runs flat 2D, entities get their render Y from one `groundY(x, z)` function that every ground-sitting object uses (the single-source-of-truth rule that ended sds's floating-prop bug class). Structures get flattened pads with smoothstep rims and declared scatter keep-out rects.

Scatter (treeline ring, rocks, flowers) is generated by seeded deterministic placement at bake time, committed as a JSON manifest, and byte-compared in a regression test. Runtime never scatters (sds measured ~489 ms of load in a runtime Poisson pass). Manifest entries carry visual transform + separate collision radius. The treeline stays inside the grass radius so nothing floats on bare ground.

Loading is all-cold: everything builds before first interaction, inside the spec/08 budget. No streaming, no impostors, no LOD ladders. A single small pasture does not need them, and sds's apparatus for four biomes is the cautionary tale.

## Asset inventory (all re-authored, painterly cel-shaded, per spec/05)

Nothing visual ships from sds. The purchased dog/farmhouse packs are not redistributable and the procedural bakes never converged on one art direction. sds GLBs may be loaded locally as dimensional reference only (fence post 2.18 m, rails at 0.5/1.2/1.9, trees normalized to ~1 m then scaled at placement).

| Asset | Notes |
|---|---|
| Sheep | THE hero asset at 200 instances. One stylized mesh, low-poly with confident silhouette; wool as chunky painterly volume, not fur. Per-instance tint variation, vertex-anim gait/ear/jiggle. A lamb variant is a nice-to-have. |
| Dog | The player. One border-collie-shaped dog, readable at both camera distances, real animation set (idle, trot, run, sit, bark). Skinned; it is one instance and can afford bones. |
| Fence + gate | Modular kit: posts, rails, the gate (which visibly swings). Weathered painterly wood. |
| Farmhouse | One house + small barn cluster as the pen's backdrop, warm window glow at golden hour. |
| Grass | The signature system. Instanced blades, TSL wind + interaction (spec/06 carries the tuned constants). |
| Trees | Treeline ring species (2-3 variants) + one hero tree in-field for shade composition. |
| Rocks, flowers, dressing | Scatter sets: rocks (3 sizes), wildflower patches, hay bales, water trough, path decal near gate. |
| Sky | Gradient sky + painterly clouds (billboard or shell), sun with god-ray-free warm haze. Drives fog. |

Every generated asset has an in-repo recipe (script or documented tool flow) that can rebake it. Opaque binaries with no authoring source are forbidden (sds's original fence blocked every visual ask until it was rebuilt procedurally). If a DCC tool authored it, commit the source file. Pipeline: bake/author to staging, review in a gallery scene, integrate, compress (gltf-transform weld/prune/dedup + meshopt).

## Atmosphere

Golden hour, permanently. No day/night cycle in v1; the game IS the hour before sunset. One Atmosphere component owns sun direction, sky, and updates `scene.fog` per frame so fog always matches the sky horizon. No per-material fog uniforms anywhere (the sds rule that kept every pass coherent for years). A feature that ships must be reachable in the shipped configuration; no lamps wired to states that cannot occur (sds shipped a dusk lamp on a scene with no dusk for eight cycles).
