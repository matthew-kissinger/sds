# Sheep Dog Sim Long Description

Sheep Dog Sim is a free browser-first 3D herding game. Guide a sheepdog around a living flock, shape its movement, recover breaks, and drive sheep through gates, corrals, portals, or a homestead pen before night falls.

The game includes four scenes: Home Field, Rolling Hills, Open Country, and Newsheepdogland. Modes range from a quiet 30-sheep practice run to 5,000-sheep chaos. Newsheepdogland adds survival pressure with wolves after dark, while online rooms support 2-4 player co-op and competitive multiplayer on a Cloudflare Worker and Durable Object backend.

Under the hood, Sheep Dog Sim uses Three.js 0.185, React 19, Vite 7, Tailwind 4, and deterministic shared simulation modules imported by both browser and server. It is free to play, has no signup or ads, and publishes current source under AGPL-3.0-or-later with current non-code assets under CC BY-SA 4.0.
