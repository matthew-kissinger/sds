# Sheep Dog Sim v2.5.0 Release Notes Draft

Status: release copy for the Cycle 111 web deploy.

## Short Version

Sheep Dog Sim v2.5.0 makes bark a real skill. Bark is more readable, more immediate, and more useful for shaping the flock, while the first-session tutorial, leaderboards, and completion screen do a better job guiding new players into quick scored runs.

## Player-Facing Notes

- Bark now has clearer power and direction, pushing sheep with a hybrid sound-wave and radial pressure response.
- Desktop and mobile HUDs now show bark readiness and cooldown.
- Bark now creates a subtle visible wave in the world so its range and timing are easier to read.
- Dog bark audio is shorter, calmer, and more immediate.
- The intro tutorial now teaches bark and keeps the first goal to 3 sheep.
- Practice completion now points players toward Quick 25 instead of implying leaderboard credit for an unranked run.
- Leaderboards now make easy scored boards and active boards easier to find.
- Completion screens now present ranked save feedback and next actions more clearly.

## Technical Notes

- Shared bark steering remains deterministic through `shared/BarkImpulse.js`.
- The bark sim-baseline fixture was intentionally regenerated only for the bark trace.
- Newsheepdogland and survival remain a gated tech sandbox in this release.
- Bark audio sources and licenses are documented in `docs/bark-audio-assets.md`.
