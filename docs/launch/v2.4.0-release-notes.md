# Sheep Dog Sim v2.4.0 Release Notes Draft

## Short Version

Sheep Dog Sim is getting a launch-readiness release: Three.js r185, refreshed fences, gates, trees, grass, farmhouse and homestead props, current SEO/store copy, an isolated preview multiplayer backend, and a full release-candidate proof pass.

## Player-Facing Notes

- Refreshed scene art across fences, gates, trees, grass, farmhouse, and homestead props.
- `sds-hybrid-v1` is now the default grass/ground-contact direction.
- Tree LOD distances are tuned by scene so panning and far tree density read more consistently.
- Newsheepdogland remains the survival island and WebGPU showcase, with better asset fit and launch copy.
- Multiplayer preview infrastructure is now isolated from production for safer PR testing.
