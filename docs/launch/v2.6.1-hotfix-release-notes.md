# Sheep Dog Sim v2.6.1 Hotfix Release Notes

Status: release source copy for the v2.6.1 web beta hotfix.

Sheep Dog Sim v2.6.1 keeps the v2.6.0 web beta posture and fixes a production WebGPU issue in Counting Sheep.

## Fixed

- Counting Sheep Incremental and Exponential now start cleanly on WebGPU in Home Field and Rolling Hills.
- The first round correctly renders one active sheep without the bright centered render artifact that could look like a sun billboard stuck in the playfield.
- Returning from Counting Sheep to the main menu clears counting round state before the next scene rebuild.

## Validation

- Local unit, build, lint, and Chromium smoke gates passed.
- Local production WebGPU Playwright screenshots verified Counting Sheep Incremental and Exponential on Home Field and Rolling Hills with no WebGPU validation errors.
