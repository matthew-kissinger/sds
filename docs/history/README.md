# History

Closed investigations and closed candidate reports. They are kept for their
reasoning and their measurements, which are often the only record of why a
constant has the value it has.

Nothing in this directory is current direction. `STATUS.md` is the current
state, `CHANGELOG.md` is the chronology, and `AGENTS.md` plus `spec/` hold the
rules that outlived the work below.
