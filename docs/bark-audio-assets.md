# Bark Audio Assets

Cycle 111 replaced the long player bark with short, calm CC0 Freesound sources
normalized into the compressed runtime assets under `assets/sounds_compressed/`.
The generated files are mono MP3, 44.1 kHz, 96 kbps, loudness-normalized near
-20 LUFS, and trimmed or padded into the 300-900 ms bark response target.
