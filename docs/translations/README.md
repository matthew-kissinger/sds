No native speaker has read any of these. Machine translation produced everything marked `new` in the review packs. Do not describe any of them as professional or official.

## Review packs

[`review-pack/`](review-pack/) has one file per language, generated by `node tools/i18n-review-pack.mjs`. Each lists every interface string, grouped by screen, with where it appears, the English, the translation, any width limit and its source. The on-screen note in Settings says no native speaker has checked the language, which stays true after an independent review, so the note stays too. Once a native speaker has read a language, set `"reviewed": true` in `app/src/i18n/locales.json`, which removes the note.

[`provenance.json`](provenance.json) records which strings match a source exactly. It is an exact-text search, so a string a translator lightly edited counts as `new`, and a short common word can match by chance. Recompute it with `--fork <dir> --v2 <dir>`.
