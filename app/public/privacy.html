Privacy

Play works without an account

Sheepdog Sim has optional online solo times. The field, completion and local personal bests keep working when the score service is unavailable.

Local data

The game stores preferences, control bindings, personal best times and a server-issued score identity in browser local storage. The identity contains a random identifier, a device secret and the current running name. Clearing site data removes the browser copy but does not delete times already submitted to the public board.

Online solo times

The score service receives the server-issued identity, running name, completion time, flock size and current field partition. A friendly random name is assigned automatically and can be replaced with a name you choose. Names and leading completion times are public. Solo score requests do not contain multiplayer results or contact information.

Multiplayer history

Online matches use a separate authoritative service. It receives movement and bark inputs to run the match. Persistent match history stores the participating random player identifiers and running names, mode, region, flock size, starting party, dates, outcomes and connection-loss/reconnect counts. It does not retain a movement replay, admission tickets, device secrets or IP addresses in the match database.

Your match history is available through your existing player identity. Participants can see their shared match results; private rooms do not appear on public lobby boards. The owner can review match activity, reliability and daily capacity-rejection totals through a protected dashboard. These records remain after a room closes and are separate from public solo times. There is no public multiplayer ranking.

Hosting

The static site and score service use Cloudflare. Cloudflare and the network providers involved may process standard request information such as IP address, user agent, requested path and timing for security and delivery operations.

Aggregate site analytics

The public site may use Cloudflare Web Analytics to count page visits and measure page-load performance. Cloudflare states that this service does not collect or use visitors' personal data. The site analytics beacon does not receive multiplayer results or control inputs. Multiplayer match records are stored separately as described above.

Source and questions

The client source is public, including the storage and network boundaries. Questions can be raised in the source repository.
