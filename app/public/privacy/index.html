Privacy

Play works without an account

Sheepdog Sim 3 has optional online solo times. The field, completion and local personal bests keep working when the score service is unavailable.

Local data

The game stores preferences, control bindings, personal best times and a server-issued score identity in browser local storage. The identity contains a random identifier, a device secret and the current running name. Clearing site data removes the browser copy but does not delete times already submitted to the public board.

Online solo times

The score service receives the server-issued identity, running name, completion time, flock size and the version 3 field partition. A friendly random name is assigned automatically and can be replaced with a name you choose. Names and leading completion times are public. The game does not send movement history, contact information or multiplayer data.

Hosting

The static site and score service use Cloudflare. Cloudflare and the network providers involved may process standard request information such as IP address, user agent, requested path and timing for security and delivery operations.

No analytics or multiplayer

The version 3 client does not send game analytics and has no room, lobby, WebSocket or multiplayer feature. Its only game-service requests are identity, rename, score submission and solo-board reads.

Source and questions

The client source is public, including the storage and network boundaries. Questions can be raised in the source repository.
