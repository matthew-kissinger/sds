Controls

  • Move with W A S D, arrow keys, the left gamepad stick or the touch joystick.
  • Hold Shift, the left trigger or Sprint to run.
  • Press Space, the right shoulder button or Bark to move nearby sheep.
  • Press C or the camera control to change view.
  • Press Escape, Menu or Pause to stop the field.

If the field does not load

  • Update the browser and reload the page.
  • Close other graphics-heavy tabs or applications.
  • Confirm hardware acceleration is enabled in the browser.
  • Try a current version of Chrome, Edge, Firefox or Safari.

Report a problem

Open an issue in the source repository with the browser, device, flock size, reproduction steps and any console error. Security reports should follow the private process in GitHub Security.
