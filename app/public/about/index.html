About the game

One dog. One flock. One field.

Sheepdog Sim 3 is a focused browser game about reading a flock, applying pressure carefully and guiding every sheep through the gate.

Why version 3 exists

The earlier game proved the simulation and the feel of herding, but years of modes and overlapping systems made the client difficult to change safely. Version 3 keeps the proven simulation and rebuilds the experience around one field and one clear path through the code.

The initial release is single-player with 25, 75 or 200 sheep. It works on desktop and mobile and uses WebGPU with a WebGL2 fallback.

Open source

The source code is available under AGPL-3.0-or-later. The repository includes the simulation, renderer, input, audio system, deterministic asset recipes and release tests.
