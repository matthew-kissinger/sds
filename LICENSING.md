# Licensing

## Overview

Sheep Dog Simulator uses separate licenses for source code and assets.

- **Code, from v2.2.0 onward:** GNU Affero General Public License v3.0 or
  later (AGPL-3.0-or-later).
- **Assets, from v2.2.0 onward:** Creative Commons
  Attribution-ShareAlike 4.0 International (CC BY-SA 4.0).

## Forward-Only Relicense

All versions up to and including **v2.1.10** remain available under the license
terms recorded in their historical commits and release artifacts.

Starting with **v2.2.0**, source code is licensed under AGPL-3.0-or-later and
non-code assets are licensed under CC BY-SA 4.0.

This is a forward-only licensing change. It does not rewrite or alter any
historical commits, tags, releases, or license grants.

## Provenance

Sheep Dog Simulator started as a Three.js game-jam entry and grew into a
production browser game with a Cloudflare Worker backend, deterministic shared
simulation modules, and a native-shell packaging path.

## Source Code

The complete source-code license is in `LICENSE`.

Modified versions, including hosted versions, must comply with the AGPL network
source-code requirements. The running game includes a visible source link to:

https://github.com/matthew-kissinger/sds

## Assets

The asset license is in `LICENSE-ASSETS`.

Unless a file states otherwise, all non-code assets in this repository are
licensed under CC BY-SA 4.0. This includes everything under `assets/` plus
models, images, audio, textures, Blender files, and baked binary asset data
committed elsewhere in the repository.
