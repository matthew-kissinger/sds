# CLAUDE.md

The contributor operating guide for this repository is [AGENTS.md](AGENTS.md).
Read it first. It is the single copy of these rules; this file exists only so
that tools looking for `CLAUDE.md` find their way there.

Do not restate or duplicate the rules here. Two copies drift, and a drifted
rule is worse than an absent one.

Quick orientation:

- `spec/00-vision.md` through `spec/13-asset-lab.md` are the product contract.
- `STATUS.md` is the current release state and the open questions.
- `CHANGELOG.md` is the chronology.
- `docs/history/` holds closed investigations, kept for reasoning only.
